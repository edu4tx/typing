# Typing Test Pro

A production-ready typing test application.

## Tech Stack
- Frontend: React 19, Vite, Tailwind CSS (v4), Framer Motion, React Icons
- Backend: Node.js, Express

## Project Structure
- `/client`: Frontend React application.
- `/server`: Backend Express application.

## Getting Started

1. **Install Dependencies**
   Run the following command at the root directory to install dependencies for both the frontend and backend:
   ```bash
   npm install
   ```

2. **Start the Application Locally**
   Run the following command at the root directory to start both the frontend and backend concurrently:
   ```bash
   npm run dev
   ```

   The backend API will run on `http://localhost:5000`.
   The frontend will run on the Vite default port (typically `http://localhost:5173`).
